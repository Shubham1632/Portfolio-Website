# Shubham Gangurde — Portfolio

Personal portfolio for Shubham Gangurde, a Full Stack Software Engineer based
in Milan, Italy.

## Stack

- React 18 and TypeScript
- Vite
- Tailwind CSS
- Framer Motion and GSAP

## Development

```bash
npm install
npm run dev
```

Additional commands:

```bash
npm run build
npm run type-check
npm run lint
npm run test
```
